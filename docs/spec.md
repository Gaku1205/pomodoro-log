# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

25分集中・5分休憩のポモドーロを回しながら、今日やったことを1行ずつ記録できるタイマーのWebサービス。（元のメモ：ポモドーロ（25分集中・5分休憩）を回しながら、今日やったことを1行ずつ残せるタイマー）

## 前提

- 使う人：ポモドーロを回しながら、今日やったことを手軽に残したい個人。アカウントは無い
- 保存：記録はブラウザの localStorage（キー `pomodoro-log:entries`）に保存する。サーバーには送らない。「今日」は端末のローカル日付で判定する
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

### トップページ（`/`）

1画面で、タイマーと今日の記録を縦に並べる。

**タイマー**
- 開くと「集中」と「25:00」を出す。停止状態で待つ
- 区間は「集中」（25分）と「休憩」（5分）。表示は mm:ss（分は2桁ゼロ埋め、例 `05:00`）
- 「開始」を押すと1秒ごとに残りが減る。動いている間、「開始」は「一時停止」に変わり、押すと止まる（残りは保持）
- 「リセット」は、いまの区間を最初の長さに戻して停止する
- 残りが0になったら、集中→休憩、休憩→集中に切り替え、新しい区間の長さを出して停止状態で待つ（自動では始めない）

**今日の記録**
- 1行のテキスト入力と「追加」ボタン。前後の空白を除いて空なら追加できない（ボタンは押せない状態にする）
- 追加すると、一覧の先頭に「HH:mm（端末のローカル時刻）＋本文」で1行出し、入力欄を空にする。集中・休憩どちらの区間でも追加できる
- 一覧は今日（ローカル日付）の分だけを新しい順に出す。前の日の記録は出さない（消さずに保存には残す）
- 記録が無いときは「まだ記録がありません」を出す
- 再読み込みしても今日の記録が残る。保存データが壊れていたら空として扱う

**ロジックの置き場**
- `src/lib/pomodoro.ts`：区間の長さ、mm:ss 表示、区間の切り替え
- `src/lib/entries.ts`：記録の追加、HH:mm の整形、今日の分の絞り込み、保存・読み込み
