# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 方針

- 避けること（「AIが作った感」の原因）：数字を大きく並べたタイル、角丸の箱を並べただけのカード、ピル型バッジの多用、グラデーション、絵文字、大きな塗りつぶしボタンの羅列

## 色

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#0A0A0B` | ページの背景 |
| `--text` | `#DEDFE3` | 本文 |
| `--muted` | `#8B8D96` | 補助の文字（時刻、区間名、空の表示） |
| `--line` | `#26272C` | 区切り線、入力欄・ボタンの枠線 |
| `--accent` | `#E8B04A` | 動作中の区間名、入力欄のフォーカス枠 |

## 文字

- 日本語は詰まって見えるので、11.5px より小さい文字は使わない
- 日本語は文節の途中で切らない（`word-break: auto-phrase`）

## トップページ

- 幅：`.container`（最大720px、左右20px）に縦1列。上から「タイマー」「記録」。区間の間は40px、要素の間は12px
- 区間名（「集中」「休憩」）：14px、`--muted`。動作中だけ `--accent`
- 残り時間（mm:ss）：56px、太さ300、`font-variant-numeric: tabular-nums`、`--text`。枠や背景は付けない（タイルにしない）
- 操作（「開始」「一時停止」「リセット」）：横に並べる。背景なし、1pxの `--line` の枠、`--text` の文字、14px、高さ36px、左右padding 16px、角丸4px。ホバー時は枠が `--muted`。塗りつぶしにしない
- 見出し「今日の記録」：14px、`--muted`
- 入力欄：背景なし、1pxの `--line` の枠、16px、高さ36px、角丸4px、フォーカス時は枠が `--accent`。プレースホルダは「やったことを1行で」（`--muted`）。横いっぱいに広げ、右に「追加」ボタン（操作と同じ見た目）
- 「追加」が押せないとき：文字と枠を `--muted` にし、カーソルは通常のまま
- 一覧：枠や背景なしの行を縦に並べ、行の間に1pxの `--line`。行は「HH:mm（`--muted`、14px、tabular-nums、幅48px）＋本文（16px）」。カードにしない
- 記録が無いとき：「まだ記録がありません」（14px、`--muted`）
- 文言：「集中」「休憩」「開始」「一時停止」「リセット」「今日の記録」「追加」「まだ記録がありません」
- 動き：付けない
